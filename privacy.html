Privacy Policy

Effective date: June 6, 2026 Last updated: June 6, 2026

🛡️ Overview

This Privacy Policy explains how DevSENSEI ("we", "our", or "the extension"), developed by georgeaprahamov, collects, uses, and protects information when you use the DevSENSEI VS Code extension and its associated landing page.

Short version: DevSENSEI does not collect, store, or sell your personal data. Selected code snippets are sent to Mistral AI's API solely to generate responses during your active session. We have no persistent access to your code.

By installing or using the DevSENSEI extension, you agree to the terms described in this policy. If you do not agree, please uninstall the extension and discontinue use.

📋 Data We Collect

We are committed to data minimisation. Below is a complete picture of what is and is not collected.

Data typeCollected?Details
Selected code snippets ✅ In-session only Sent to Mistral AI API to generate mentor responses. Not stored by us.
Chat messages (your input) ✅ In-session only Sent alongside code context to Mistral AI. Not stored by us.
Mistral AI API key ✅ Locally only Stored in VS Code's extension settings on your machine. Never transmitted to us.

Cookie consent preference ✅ localStorage We store your cookie consent choice in your browser's localStorage so we don't ask again. No tracking involved.
Tracking / analytics cookies ❌ None We run no analytics, ad-tech, or behavioural tracking on this site.

🔧 How We Use Data

The only data processing that occurs is:

  • Generating mentor responses — your selected code and chat messages are forwarded to the Mistral AI API to produce the Socratic guidance you receive. This is the core function of the extension.
  • Maintaining conversation context — a rolling window of recent messages (configurable via devsensei.maxHistory) is kept in memory during your active VS Code session to allow coherent multi-turn dialogue. This is cleared when the panel is closed or VS Code is restarted.

We do not use your data for advertising, profiling, training AI models, or any purpose beyond delivering the mentor responses you requested.

🔗 Third-Party Services

Mistral AI

DevSENSEI uses Mistral AI's API to process code snippets and generate responses. When you invoke the mentor, your selected code and conversation history are transmitted to Mistral AI's servers.

Mistral AI's own privacy practices govern how they handle this data. We strongly encourage you to review the Mistral AI Privacy Policy before use.

Important: Do not send sensitive credentials, passwords, secrets, or personally identifiable information to the mentor. Treat it as you would any third-party API.

VS Code Marketplace & Open VSX

When you install DevSENSEI via the VS Code Marketplace or Open VSX Registry, those platforms may collect installation and usage statistics under their own privacy policies. DevSENSEI has no control over this data.

Google Fonts

This landing page loads fonts from Google Fonts. Google may log your IP address when serving font files. See the Google Privacy Policy for details.

🗓️ Data Retention

DevSENSEI does not maintain any server-side database or persistent storage of user data.

  • Chat history — stored in memory only for the duration of your active VS Code session. Cleared on panel close or VS Code restart.
  • API key — stored locally in your VS Code settings.json. Under your full control. Delete it at any time via VS Code settings.
  • Mistral AI — subject to Mistral AI's own data retention policies. Refer to their privacy documentation.

✅ Your Rights

Because we collect no personal data, there is nothing to access, correct, or delete on our end. However, you have full control over:

  • Your API key — view, change, or remove it at any time in VS Code settings
  • Session history — clear it by closing the DevSENSEI panel or restarting VS Code
  • Extension data — uninstall the extension to remove all locally stored settings
  • Mistral AI data — contact Mistral AI directly to exercise your rights under GDPR or other applicable regulations

If you are located in the European Economic Area (EEA) or United Kingdom and have questions about data rights in relation to Mistral AI's processing, contact us at the address below and we will assist where we can.

🔒 Security

All communication between the extension and the Mistral AI API is transmitted over encrypted HTTPS connections. Your API key is stored in VS Code's settings mechanism on your local machine and is never transmitted to our servers.

While we take reasonable precautions to protect data in transit, no internet transmission is 100% secure. Use good judgment about what code you share — avoid including secrets, tokens, or sensitive credentials in code you send to the mentor.

👶 Children's Privacy

DevSENSEI is not directed at children under the age of 13. We do not knowingly collect any information from children. If you believe a child has used the extension in a way that transmits personal data, please contact us so we can investigate.

📝 Policy Changes

We may update this Privacy Policy from time to time. When we do, we will update the "Last updated" date at the top of this page. For significant changes, we will post a notice in the extension's changelog on the VS Code Marketplace.

Continued use of the extension after a policy update constitutes your acceptance of the revised policy.
