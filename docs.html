🧠 Overview #

DevSENSEI is an AI-powered Socratic coding mentor built directly into Visual Studio Code. Instead of generating copy-paste solutions, it guides you through targeted questions and hints — helping you understand why something is wrong, not just what to change.

It draws on the Socratic Method: a dialogue-based approach that builds lasting understanding by encouraging you to discover the answer yourself.

💡 Why Socratic? Research consistently shows that self-discovery of errors leads to deeper knowledge retention and builds the kind of critical engineering thinking that differentiates great developers.

Key Capabilities

  • Guided Debugging — pinpoints logical errors through leading questions rather than giving direct answers
  • Intelligent Logic Auditing — analyses your code's control flow and surface surprising edge cases
  • Architectural Advice — discusses design trade-offs and suggests structural improvements
  • Real-time Streaming — responses appear token-by-token via SSE with zero perceived latency
  • Context Awareness — understands the selected code block and surrounding file context

🚀 Installation #

DevSENSEI can be installed from either the VS Code Marketplace or the Open VSX Registry (for VS Codium / other editors).

Option A — VS Code Marketplace (recommended)

1
Open the Extensions panel

Press Ctrl+Shift+X (Windows/Linux) or Cmd+Shift+X (macOS) inside VS Code.

2
Search for DevSENSEI

Type DevSENSEI in the search box and look for the extension published by georgeaprahamov.

3
Click Install

The extension activates immediately. No restart required, no API key needed to start.

⚙️ Configuration #

Open VS Code Settings (Ctrl+, / Cmd+,) and search for DevSENSEI to see all options. You can also edit settings.json directly.

Setting Type Default Description
devsensei.mistralApiKey string empty (built-in) Your personal Mistral AI API key. Leave empty to use the built-in fallback key.
devsensei.mistralModel enum codestral-latest The AI model that powers responses. Options: codestral-latest, mistral-large-latest.
devsensei.language enum auto Conversation language: auto (detect from your message), en (English), bg (Bulgarian).
devsensei.maxHistory number 15 Maximum chat messages kept in context. Higher values = richer context, more tokens used.
devsensei.mentorshipLevel enum strict Teaching style: strict (pure Socratic hints), balanced (hints + occasional hints), direct (direct answers with explanations).

Example settings.json snippet

{
  "devsensei.mistralApiKey": "your-key-here",
  "devsensei.mentorshipLevel": "balanced",
  "devsensei.language": "en",
  "devsensei.maxHistory": 20
}

⌨️ Keyboard Shortcuts #

DevSENSEI registers a global keybinding that opens the mentor panel with the currently selected code pre-loaded.

OSShortcut
🍏 macOS Cmd+Option+A
💻 Windows / Linux Ctrl+Alt+A

Rebinding the shortcut

Open the VS Code Keyboard Shortcuts editor (Ctrl+K Ctrl+S), search for devsensei.askMentor, and assign any key combination you prefer.

Context menu

Right-click on any selected code block in the editor. You will see "Ask DevSENSEI" in the context menu as an alternative to the keyboard shortcut.

📖 Usage Guide #

1
Select your code

Highlight any snippet in your editor — a function, a loop, a class, or even a single suspicious line.

2
Invoke the mentor

Press Cmd+Option+A (macOS) / Ctrl+Alt+A (Windows), or right-click and choose Ask DevSENSEI.

3
Engage in dialogue

The side panel opens with your code pre-loaded. DevSENSEI starts with a focused question. Type your thoughts freely in the input box and work toward the solution together.

4
Apply your understanding

Once you've identified the issue through dialogue, fix your code. DevSENSEI can then verify your solution or explore related edge cases.

Tip: The more honest your responses to the mentor's questions, the more accurately it can detect your exact knowledge gap and give you precisely targeted guidance.

🎓 Mentorship Modes #

DevSENSEI offers three distinct modes to match your current needs. Switch at any time via devsensei.mentorshipLevel in settings.

ModeBehaviourBest for
strict Only asks questions. Never reveals the answer directly. Pure Socratic dialogue. Learning new concepts, deliberate practice, interview preparation.
balanced Asks guiding questions but provides partial hints when you're stuck. Day-to-day debugging, unfamiliar codebases.
direct Gives direct answers with explanations. Minimal back-and-forth. Tight deadlines, reviewing code you wrote long ago.

❓ FAQ #

Is DevSENSEI completely free?

Yes. Install and use it for free. The built-in fallback API key gets you started with no sign-up. For unlimited or higher-volume usage, provide your own Mistral AI API key in settings.

Which programming languages are supported?

DevSENSEI is language-agnostic. It works with JavaScript, TypeScript, Python, Rust, Go, C++, Java, C#, PHP, Ruby, HTML/CSS, SQL, and any other language Mistral's models understand — which is essentially all mainstream languages.

What if I'm stuck and just need the answer?

Change devsensei.mentorshipLevel to direct in settings. This switches the mentor to a more traditional Q&A mode while still providing explanations alongside the answer.

Is my code sent to any third-party servers?

Selected code snippets are sent to Mistral AI's API to generate responses. No code is stored or logged by DevSENSEI itself. See our Privacy Policy and Mistral AI Privacy Policy for full details.

How do I report a bug or request a feature?

Join our Discord server to report issues, suggest features, or get direct support from the team.

Does DevSENSEI work offline?

No — DevSENSEI requires an internet connection to reach the Mistral AI API and generate responses. There is no local inference mode at this time.
